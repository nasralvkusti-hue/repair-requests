# Система учёта заявок на ремонт транспорта

Учебный проект: настольное приложение на C# (WinForms, .NET 10) с базой данных SQLite,
статусами заявок и расчётом среднего времени ремонта.

Репозиторий: <https://github.com/nasralvkusti-hue/repair-requests>

## Запуск из Visual Studio

Приложение запускается из Visual Studio.

1. Откройте файл **`RepairRequests.slnx`** в Visual Studio 2022 (17.13 и новее)
   или Visual Studio 2026.
2. В обозревателе решений убедитесь, что запускаемым проектом выбран
   **`RepairRequests.WinForms`** (правый щелчок → «Назначить запускаемым проектом»).
3. Нажмите **F5** (с отладкой) или **Ctrl+F5** (без отладки).
4. Дождитесь окна входа. При первом запуске подготовка базы данных и прогрев
   .NET могут занять **10–40 секунд** — на экране отображается заставка
   «Подготовка к запуску», окно закрывать не нужно.
5. Войдите под одной из демонстрационных учётных записей (они же указаны
   на форме входа).

При первом запуске из Visual Studio база данных создаётся автоматически в каталоге
`src\RepairRequests.WinForms\bin\Debug\net10.0-windows\data`.

## Требования

- Windows 10/11 x64.
- Visual Studio 2022 (17.13 и новее) или Visual Studio 2026 с рабочей нагрузкой
  «Разработка классических приложений .NET».
- .NET 10 SDK — устанавливается вместе с рабочей нагрузкой Visual Studio.

Проверить установленные компоненты:

```powershell
dotnet --list-runtimes
dotnet --version
```

## Сборка, тесты и публикация

Эти команды нужны для проверки и подготовки релиза. Для разработки
и демонстрации приложение запускайте из Visual Studio.

```powershell
# сборка всего решения
dotnet build RepairRequests.slnx

# модульные тесты (133 теста)
dotnet test RepairRequests.slnx

# публикация готовой версии (только для передачи на другой компьютер)
dotnet publish src\RepairRequests.WinForms\RepairRequests.WinForms.csproj `
  -c Release -r win-x64 --self-contained false -o publish\win-x64
```

## Где хранятся данные

При запуске из Visual Studio файлы создаются рядом со сборкой, в каталоге
`src\RepairRequests.WinForms\bin\Debug\net10.0-windows`:

- `data\repair-requests.db` — база данных SQLite;
- `logs\app-*.log` — журнал работы и ошибок;
- `reports\` — выгруженные отчёты Excel и PDF.

Чтобы начать с чистой демонстрационной базы, закройте программу и удалите
файлы `data\repair-requests.db`, `data\repair-requests.db-shm`,
`data\repair-requests.db-wal`. При следующем запуске база будет создана заново
с тем же набором демонстрационных данных.

## Структура проекта

```text
src\RepairRequests.Core       — модели, EF Core, репозитории, сервисы, экспорт
src\RepairRequests.WinForms   — формы WinForms, оформление, запуск

```

## Если приложение не запускается

1. Посмотрите последние строки журнала
   `src\RepairRequests.WinForms\bin\Debug\net10.0-windows\logs\app-*.log`.
2. Убедитесь, что в Visual Studio запускаемым проектом назначен
   `RepairRequests.WinForms`, а решение собрано без ошибок.
3. Проверьте, что установлен .NET 10 SDK:
   `dotnet --version` (нужна версия 10.x).
4. Если проект находится в папке OneDrive/облачной синхронизации, первый запуск
   может быть заметно медленнее — дождитесь окончания заставки.
5. Не запускайте приложение повторно, пока открыто его окно: второй экземпляр
   откроет ещё одно окно программы.
